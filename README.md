# Qwen 校园内网聊天页（第一版 / v1）

基于深圳城市职业学院**校园内网**推理服务（vLLM，OpenAI 兼容，模型 `qwen3.5-122b`）的网页聊天客户端。

本目录为**第一版（v1）**：仅支持纯文本对话，不含文件/图片附件。

## 目录文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 聊天页面。HSR 风格深色 UI，支持流式输出、思考过程折叠、Markdown 渲染（代码块带复制）、对话本地保存（localStorage）。 |
| `chat-server.py` | 本地代理服务，监听 `127.0.0.1:8000`，将 `/v1/*` 透传至内网 `http://10.1.88.114:8001`。仅用 Python 标准库。 |
| `start-chat.bat` | 一键启动脚本。通过 `%~dp0` 自动定位本目录，打开 Edge 至 `http://localhost:8000` 并拉起代理。 |

## 运行步骤

1. 连接**校园网**（该服务仅校内 `10.x` 网段可达，公网 / VPN 不可达）。
2. 双击 `start-chat.bat`（或在本目录自行运行 `python chat-server.py`）。
3. 浏览器访问 `http://localhost:8000`。
4. 若页面顶部弹出警告，说明你是直接双击打开的 `index.html`——请改用 `http://localhost:8000` 访问。

## 为什么需要本地代理

内网服务对普通请求返回 `access-control-allow-origin: *`，但浏览器跨域预检（`OPTIONS`）返回 `403`，导致网页无法直接从浏览器调用 API。本地代理在同机 `127.0.0.1:8000` 转发请求，绕开该限制。

## 模型与接口细节

- 默认开启「深度思考」（`chat_template_kwargs: {enable_thinking: true}`）。若接口返回 400 且报错含 `enable_thinking`，页面会自动去掉该参数重试。
- 思考链在流式 `delta.reasoning` 字段，正文在 `delta.content`。
- 页面会自动调用 `/v1/models` 检测在线状态与可用模型，离线时给出「校园网 / 服务 / 代理」排查提示。
