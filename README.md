# 量子方块：虚空协议 · Quantum Tetris: Void Protocol

> 基于 HTML5 Canvas + JavaScript 的赛博朋克 / 太空科幻风格网页版俄罗斯方块。
> 玩家扮演太空站的主控 AI，通过排列「数据碎片」修复受损的防火墙。

## 项目信息

- **主题名称**：量子方块：虚空协议 (Quantum Tetris: Void Protocol)
- **运行环境**：单文件 HTML（内联 CSS + JS），无需构建，双击即可在浏览器运行
- **主文件**：`index.html`
- **当前状态**：✅ 已完成可玩版本（含完整视觉特效与游戏机制）

## 视觉风格 (Sci-Fi Aesthetics)

- **背景**：深空黑 `#050510`，叠加缓慢漂移的星空 + 淡绿「矩阵雨」粒子
- **网格**：微弱青色网格线 `#004444`，带轻微霓虹发光
- **方块（数据碎片）**：全息风格 —— 半透明填充 + 高亮霓虹边框，非纯色
  - I 青色 · O 黄色 · T 紫色 · S 绿色 · Z 红色 · L 橙色 · J 蓝色
- **特效**
  - 消除行：屏幕轻微震动 + 方块炸裂为粒子碎片
  - 旋转：方块周围短暂电流（电弧）特效
  - UI：等宽字体（Orbitron / Courier New）+ CRT 扫描线 + 暗角滤镜
- **主题化 HUD**：得分 / 修复行数 / 层级 / 「防火墙完整度」进度条

## 游戏机制 (Game Mechanics)

- 标准俄罗斯方块：7 种方块、7-bag 随机、SRS 简化旋转 + 简单踢墙
- 软降、硬降、Ghost 落点预览、Hold 暂存、Next 预览
- 消行计分（1/2/3/4 行 = 100/300/500/800 × 层级），每 10 行升一级并加速
- 锁定延迟（落地 500ms 内可继续微调）
- 暂停 / 静音 / 重启；游戏结束 / 暂停显示统计（含时长）

### v2.0 更新亮点（2026-10-17, Step-5Preview）
- **玩法**：连击 Combo 与 Back-to-Back（Tetris）计分、localStorage 最高分持久化、Next 队列显示 3 个、暂停面板显示统计与时长
- **特效**：WebAudio 背景音乐（小调五声缓慢琶音 + 低音脉冲）、开场 BOOT 过场动画、连击 / Tetris / 升级横幅提示
- **移动端**：屏幕方向键 / 旋转 / 硬降 / 暂存按钮（带按住连发 DAS）+ 棋盘滑动手势（左右移动、下滑软降/硬降、点按旋转），响应式布局
- **手感**：DAS/ARR 自动位移、软降加速、可重置的锁定延迟（带上限）、更顺的下落速度曲线与升级节奏

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `←` `→` | 左右平移 |
| `↓` | 软降 |
| `↑` / `X` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `SPACE` | 硬降（直接落底） |
| `C` | 暂存碎片（Hold） |
| `P` | 暂停 / 继续 |
| `M` | 静音切换 |

## 如何运行

1. 直接用浏览器打开 `index.html`（推荐 Chrome / Edge）。
2. 点击「初始化协议 ▸ INITIATE」开始游戏（首次点击同时激活音效）。
3. 如需离线运行，字体将自动回退到 `Courier New`。
