# 千问校园版 · VS Code 侧边栏扩展

在 VS Code **侧边栏**直接对话校园内网 Qwen3.5-122b（方式二：像 Copilot 一样在边栏聊天）。

- 活动栏出现「千问」图标，点开即聊天框。
- 流式输出 +「思考过程」折叠。
- 深度思考开关、温度调节、多轮上下文。
- 代理未启动时，点「启动服务」一键拉起 `../chat-server.py`（代理退出的窗口关闭时自动回收）。

## 运行（调试 / 使用）

1. 用 **VS Code 单独打开本文件夹** `D:\1\122\深圳城市职业学院校园版AI模型\vscode-qwen-chat`（文件 → 打开文件夹）。
   > 注意：要单独打开这个子文件夹，不是外层 `D:\1\122\深圳城市职业学院校园版AI模型`，否则 `F5` 会跑成 chat-server 而不是扩展宿主。
2. 按 `F5`（配置名「运行扩展」）→ VS Code 会开一个 **扩展开发宿主** 新窗口。
3. 在新窗口左侧活动栏点「千问」图标 → 侧边栏出现对话界面，直接输入即可。
4. 关掉扩展开发宿主窗口即卸载扩展。

## 原理

扩展宿主（`extension.js`）通过 `http` 把请求发到本地代理 `http://127.0.0.1:8000/v1/chat/completions`，
解析 SSE 流并把 `delta.content` / `delta.reasoning` 片段经 `postMessage` 推给侧边栏 Webview（`webview/chat.js`）。
代理未连时自动 `spawn python ../chat-server.py`。

## 依赖

- 仅用 VS Code API 与 Node 内置 `http`，**无需 npm install**。
- 本机需有 `python` 命令（代理用标准库，无第三方依赖）。

## 命令与设置

- **打开对话**：活动栏点「千问」图标；或在命令面板（`Ctrl+Shift+P`）输入 `千问: 打开侧边栏对话`。
- **设置项**（设置界面搜索 `qwenCampus`）：`host` / `port` / `model` 均可改，默认 `127.0.0.1:8000` 与 `qwen3.5-122b`。无需任何 API Key——内网代理无鉴权，这正是比云端 API 方案省事的地方。

## 说明

- 内网服务仅校园网 `10.x` 段可达，公网 / VPN 不可达。
- 与外层网页版聊天页（`index.html`）共用同一模型与代理，只是入口不同。
