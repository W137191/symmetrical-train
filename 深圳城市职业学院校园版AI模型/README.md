# Qwen 校园内网聊天页（网页版风格增强版）

基于深圳城市职业学院**校园内网**推理服务（vLLM，OpenAI 兼容，模型 `qwen3.5-122b`）的网页聊天客户端，界面与功能对齐**网页版千问（Qwen）122b**。

## 功能特性（对齐网页版千问）

- **多会话管理**：侧栏新建 / 切换 / 删除对话，标题自动取首条消息。
- **消息级操作**：每条助手消息可「重新生成」；每条用户消息可「编辑（截断后重发）」、「复制」、「删除」。
- **附件 / 多模态**：📎 上传图片（自动压缩至 1280px）与文本文件（txt/md/代码等），支持**拖拽**与**粘贴图片**；多模态请求体安全构造，规避历史 400 错误。
- **导出对话**：当前会话一键导出为 Markdown（`.md`）。
- **明暗主题**：右上角 🌙/☀️ 切换。
- **流式输出 + 思考折叠**：思考链在 `delta.reasoning`，正文在 `delta.content`，可展开查看。
- **Markdown 渲染**：标题 / 列表 / 引用 / 代码块（带复制按钮）/ 行内代码。
- **对话本地保存**：全部存于浏览器 `localStorage`（按会话管理）。
- **参数与状态**：温度、最大生成长度、系统提示词、深度思考开关、模型自动检测（`/v1/models`）、离线排查提示。
- **联网搜索开关**：网页版有，本页保留按钮但**本地部署接口暂不支持**，点击会提示。

> 说明：官方网页版的部分能力（真正的联网搜索、Artifacts 代码执行、语音输入）依赖云端服务，本地 vLLM 不支持，故以 UI 占位 + 提示方式实现。

1. 连接**校园网**（该服务仅校内 `10.x` 网段可达，公网 / VPN 不可达）。

## 为什么需要本地代理

内网服务对普通请求返回 `access-control-allow-origin: *`，但浏览器跨域预检（`OPTIONS`）返回 `403`，导致网页无法直接从浏览器调用 API。本地代理在同机 `127.0.0.1:8000` 转发请求，绕开该限制。

## 模型与接口细节

- 默认开启「深度思考」（`chat_template_kwargs: {enable_thinking: true}`）。若接口返回 400 且报错含 `enable_thinking`，页面会自动去掉该参数重试。
- 思考链在流式 `delta.reasoning` 字段，正文在 `delta.content`。
- 页面会自动调用 `/v1/models` 检测在线状态与可用模型，离线时给出「校园网 / 服务 / 代理」排查提示。

## 使用示例

1. 双击桌面 `QwenChat.bat` → 自动打开 Edge 至 `http://localhost:8000` 并启动本地代理。
2. 顶部状态：已连上内网服务时模型名正常显示；离线时仍可打开页面，但发送会提示排查校园网 / 服务 / 代理。
3. 输入问题，`Enter` 发送、`Shift+Enter` 换行；可点 📎 上传图片或文本文件再发送；回答流式显示，可展开「思考过程」。
4. 想重来：助手消息点「重新生成」；自己写错：用户消息点「编辑」会截断后续并重新生成。
